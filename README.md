# GlamourGems

GlamourGems is a PHP and MySQL jewelry store application designed to run locally with XAMPP.

## Local setup

1. Copy the project into `C:\xampp\htdocs\GlamourGems 6`.
2. Start Apache and MySQL from XAMPP.
3. Create a MySQL database named `glamourgems`.
4. Import `database/glamourgems.sql`.
5. Check the local values in `config/config.php` and `config/database.php`.
6. Open `http://localhost/GlamourGems%206/`.

Generated uploads are ignored by Git. The SQL schema and application source remain tracked so the project can be developed and shared safely.
